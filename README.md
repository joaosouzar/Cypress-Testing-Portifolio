# 🧪 Cypress Testing Portfolio

## 📌 Sobre o Projeto

Este repositório apresenta um portfólio de testes automatizados utilizando **Cypress**, com o objetivo de demonstrar conhecimentos práticos em **Quality Assurance (QA)** e automação de testes end-to-end.

Os testes simulam cenários reais de navegação em um e-commerce, cobrindo funcionalidades como cadastro, login, busca de produtos, página inicial e processo de checkout.

---

## ✅ Conteúdo Disponível

### Casos de Teste

A pasta `cypress/casos-de-teste` contém a documentação dos cenários validados:

- Cadastro
- Login
- Checkout
- Página inicial
- Produtos

### Testes Automatizados

Os testes em `cypress/e2e` foram desenvolvidos com Cypress e incluem validações positivas e negativas das principais funcionalidades:

- `Cadastro.cy.js`
- `Login.cy.js`
- `checkout.cy.js`
- `pagina.home.cy.js`
- `produtos.cy.js`
- `teste.cy.js`
